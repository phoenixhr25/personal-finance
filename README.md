# 个人资产收益整合表

> 用管理会计利润表的思维，把你的资产按流动性分层，算出每一层的 NPV、年化收益率和退休推算。

---

## 口径更新说明（2026 年 9–10 月）

导入旧配置后数字有变化，属于口径修正，不是故障：

- **保险 NPV 变低**：满期金额按"已包含现金价值"处理，NPV = 满期金现值 − 剩余保费现值，现金价值不再重复计入。
- **养老金现值变低**：从开始领养老金的日期起算，退休到领金之间的过渡期不再计入。
- **养老金推算更新**：按 2025 年起的渐进式延迟退休规则，填写出生年月和原法定退休年龄后自动推算领金日期；个人账户计入今后的缴费；和退休支出比较前按通胀率折算成今天的购买力。
- **退休判断按今日购买力**：退休时的资产先按通胀率折合今天的购买力，再和按今天物价算的目标比较。安全边际会比以前小，达标与否的判断更保守。
- **默认参数更新**：个人账户记账利率默认 1.5%（2025 年公布值），计发基数增速默认 2%，深圳计发基数 11,293 元。**已保存的配置不会自动改**，请在侧边栏手动更新后重新导出。
- **配置文件升级到 v2**，旧文件可以直接导入。导出的配置里含余额、持仓和出生年月，请不要公开粘贴。

## 这是什么

个人财务分析工具，提供两个入口：

- **Streamlit Web App**（`app.py`）：交互式界面，侧边栏填参数，一键运行，支持情景模拟、压力测试、导出 JSON 配置
- **Jupyter Notebook**（`income_statement_template.ipynb`）：逐格填写，适合逐项核对和定制计算逻辑

两个入口共享同一套计算引擎（`finance_engine.py`），参考**管理会计利润表结构**设计：

- 资产按流动性从上到下排列（养老金 → 储蓄险 → 基金 → A股 → 现金）
- 自动拉取 A股/基金实时行情，无需手动更新价格
- 计算每层 NPV、年化收益率、加权平均收益率
- 四期对比（基期 / 对比节点 / 当前 / 退休目标），看清资产积累轨迹
- 退休推算：按各层独立利率，告诉你退休那年资产预计是多少
- **情景模拟**（V2）：继续工作 / 收入中断 12 个月 / 半退休，对比退休时总资产和缺口
- **养老金调整视角**：把养老金月领金额从退休支出中剥离，精确算出投资组合需要覆盖多少
- **压力测试**：市场下跌 / 通胀 / 养老金打折 / 低收益率等 6 种冲击下的资产变化

**适合人群**：有社保、公积金、储蓄险、基金、A股、银行存款的在职人员，想把所有资产放在一张表里看清楚。

## 快速开始

### 1. 安装依赖

```bash
pip install akshare numpy-financial pandas matplotlib python-dateutil streamlit
```

> 或在 notebook 第一格执行，会自动安装（Streamlit 除外）。

### 2a. 启动 Streamlit App（推荐）

```bash
streamlit run app.py
```

浏览器自动打开，左侧侧边栏逐项填写 → 点击「🚀 运行计算」→「💾 导出配置」保存 JSON 配置文件。

### 2b. 使用 Jupyter Notebook

打开 `income_statement_template.ipynb`，按顺序填写以下几格（每格都有 `📋` 标注）：

| 步骤 | 内容 | 数据来源 |
|---|---|---|
| 全局参数 | 折现率、退休日期、寿命预期 | 自行设定 |
| 养老保险 | 个人账户余额、预计月领 | 社保 App |
| 住房公积金 | 余额、利率 | 公积金 App |
| 储蓄险 | 现金价值、IRR、满期金额 | 保单合同 |
| 基金 | 代码、份额、成本净值 | 券商 App |
| A股/ETF | 代码、股数、成本价 | 券商 App |
| 银行存款 | 账户余额、利率 | 银行 App |
| 历史快照 | 两个过去时间点的资产估算 | 回忆/估算即可 |

> 参考 `config_example.py` 查看完整参数说明。

### 3. 运行

```bash
jupyter notebook income_statement_template.ipynb
```

或全部执行（无需打开浏览器）：

```bash
jupyter nbconvert --to notebook --execute --inplace \
  --ExecutePreprocessor.timeout=120 \
  income_statement_template.ipynb
```

## 核心概念

### 为什么按流动性排列？

管理会计利润表从固定成本到变动成本逐层剥离，这里从最难变现的资产（养老金）到最易变现（现金）逐层展示，帮助你理解**真实可动用资产结构**。

### NPV 是什么？

Net Present Value（净现值）。用折现率把未来的钱折算到今天的价值。养老金的 NPV 远高于账户余额，因为它是终身年金——你会一直领到死。

### `PROJ_INVEST_RATE` vs `weighted_return`

| 指标 | 含义 | 能用于预测？ |
|---|---|---|
| `weighted_return` | 当前持仓历史年化（含浮盈） | ❌ 不能——会被高涨标的扭曲 |
| `PROJ_INVEST_RATE` | 你对未来投资收益的假设 | ✅ 能——这才是退休推算的输入 |

历史 CAGR 也不等于投资回报率——它包含了工资转入、社保缴纳等"增量资金"，放大了增长数字。

### 行情自动获取

- **A股 / 场内 ETF**：新浪财经实时行情
- **开放式基金**：天天基金盘中估值接口
- 网络问题时自动回退到买入成本，不会报错

## 常见问题

**Q：基金名称显示代码而不是名称？**  
A：行情接口访问失败，代码作为备用显示。检查网络连接，或在 `manual_nav` 字段手动填入净值。

**Q：在公司/学校网络下无法获取行情？**  
A：接口直连境内服务器（新浪/天天基金），一般不受限制。若有系统代理，notebook 已内置绕过逻辑。

**Q：如何添加港股 / 美股？**  
A：目前仅支持 A股、场内ETF、境内开放式基金。港美股可填 `manual_price` 手动录入现价。

**Q：退休推算数字怎么理解？**  
A：是按各层独立利率的机械推算，不含未来工资转入。把它理解为"如果你今天停止工作，纯靠现有资产复利到退休"的保守估算。
